# Лабораторная работа №2: Моделирование задачи N тел методом молекулярной динамики с деревом Барнса–Хата

Компьютерная модель гравитационной задачи N тел, реализованная на Python с использованием библиотек NumPy, Matplotlib и Click. Программа моделирует гравитационное взаимодействие множества частиц и сравнивает два метода расчёта сил: прямой (Particle–Particle, PP) и приближённый с использованием дерева Барнса–Хата (Barnes–Hut, BH).

## 1. Краткое описание модели

Задача N тел — это классическая задача молекулярной динамики, в которой каждая частица взаимодействует со всеми остальными по закону всемирного тяготения. Прямой расчёт сил требует O(N²) операций на каждом шаге по времени. Для больших N это становится вычислительно неприемлемым, поэтому используется приближённый метод дерева Барнса–Хата, снижающий сложность до O(N log N).

### Основные понятия

- **Частицы** — материальные точки с массой, положением и скоростью.
- **Сила** — вычисляется по закону Ньютона.
- **Метод Верле** — численное интегрирование уравнений движения.
- **Дерево Барнса–Хата** — иерархическая структура (квадродерево в 2D), позволяющая приближённо считать силы от далёких групп частиц как от одной частицы.
- **Критерий θ** — параметр раскрытия узла дерева.
- **Softening (ε)** — параметр мягкости, устраняющий сингулярность при r → 0.

### Математическая модель

Закон всемирного тяготения:

    F_ij = G · m_i · m_j / (|r_ij|² + ε²)^(3/2) · r_ij

Уравнение движения:

    m_i · d²r_i / dt² = Σ_j F_ij

Интегрирование методом Верле:

    r(t + Δt) = r(t) + v(t)·Δt + ½·a(t)·Δt²
    v(t + Δt) = v(t) + ½·[a(t) + a(t + Δt)]·Δt

Критерий Барнса–Хата (раскрытие узла):

    если s / d < θ — узел считается одной частицей,
    иначе — раскрывается на 4 дочерних узла,

где s — размер узла, d — расстояние до центра масс узла.

## 2. Возможности и ограничения

✅ Возможности

- Два метода расчёта сил: прямой (PP) и дерево Барнса–Хата (BH).
- Интегрирование методом Верле.
- Устранение сингулярности через softening.
- Сравнение производительности PP и BH при N = 50…5000.
- Визуализация: GIF-анимация, график энергий, график времени.
- CLI через библиотеку `click`.
- Воспроизводимость экспериментов (фиксированный seed).

⚠️ Ограничения

- Модель двумерная (2D).
- Нет релятивистских эффектов.
- Softening вносит небольшое искажение потенциала.
- При очень большом N (десятки тысяч) система теряет устойчивость из-за накопления ошибок интегрирования.

## 3. Инструкция по запуску

### Установка зависимостей

    pip install -r requirements.txt

### Основной запуск

    python nbody_barnes_hut.py --n 500 --steps 2000 --method bh

### Параметры CLI

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--n` | 500 | Число частиц |
| `--steps` | 2000 | Число шагов по времени |
| `--method` | bh | Метод: bh (Барнс–Хат) или pp (прямой) |
| `--save-every` | 20 | Сохранять кадр каждые N шагов |
| `--seed` | 42 | Seed генератора |
| `--output` | results | Папка для результатов |

### Замер производительности

    python time_benchmark.py

Запускает сравнение PP и BH при N = 50, 100, 200, 500, 1000, 2000, 5000 и сохраняет график.

|---|---|
| `nbody.gif` | GIF-анимация движения частиц |

## 5. Как интерпретировать результаты

**nbody.gif** — частицы (белые точки) на чёрном фоне. Видно:
- центральное плотное ядро (гравитационный коллапс);
- разреженное гало из выброшенных частиц;
- возможны подскопления.

**nbody_energy.png** — три кривые:
- кинетическая энергия;
- потенциальная энергия;
- полная энергия (должна сохраняться).

В начальный момент система неравновесная, поэтому полная энергия колеблется. Это нормально для модели N тел с коллапсом.

**nbody_time.png** — две линии на лог-лог графике:
- PP растёт как N²;
- BH растёт как N log N;
- **кроссовер на N ≈ 150**: при N > 200 BH становится быстрее.

На N = 5000 BH быстрее PP примерно в 11 раз.

## 7. Параметры модели и их влияние

| Параметр | Смысл | Типичное значение | Влияние |
|---|---|---|---|
| N | Число частиц | 200–2000 | Больше — реалистичнее, но медленнее |
| DT | Шаг по времени | 0.005 | Меньше — точнее |
| θ | Критерий Барнса–Хата | 0.5 | Меньше — точнее, но медленнее |

| `--method` | Метод | bh | pp — только для сравнения |

## 8. Результаты сравнения методов

Замеры времени одного расчёта сил:

| N | PP, с | BH, с | BH / PP | Кто быстрее |
|---|---|---|---|---|
| 50 | 0.0073 | 0.0125 | 1.71 | PP |
| 100 | 0.0295 | 0.0368 | 1.25 | PP |
| 200 | 0.1251 | 0.1073 | 0.86 | BH |
| 500 | 0.7575 | 0.3727 | 0.49 | BH (2×) |
| 1000 | 3.0178 | 0.9532 | 0.32 | BH (3×) |
| 2000 | 11.9738 | 2.2386 | 0.19 | BH (5×) |
| 5000 | 74.9844 | 6.8117 | 0.09 | BH (11×) |

**Кроссовер наблюдается при N ≈ 150.** При N = 5000 дерево Барнса–Хата быстрее прямого расчёта в 11 раз.
